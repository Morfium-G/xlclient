## Provenance

This source tree is a fork of [SatyPardus/wowdecomp](https://github.com/SatyPardus/wowdecomp),
which is itself a decompilation of the World of Warcraft 3.3.5a client (`Wow.exe`, build 12340),
a work owned by Blizzard Entertainment.

Upstream carries no license, and a decompilation cannot be licensed by the party that produced it.
No copyright grant is therefore made or implied over this tree, and none is received by forking it.

## What this means in practice

- No `LICENSE` file sits at the root of this repository, and adding one would assert rights nobody
  in the chain holds.
- This repository is source, not a distribution. No game binary and no game asset is published here.
- Building it requires an original 3.3.5a client installation that the builder already owns.
